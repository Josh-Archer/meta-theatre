Meta Theatre transforms current model cloud coverage, layer fractions, and
weather codes into modeled orbital cloud density. This is an artistic
interpretation of sampled weather conditions, not satellite imagery or a
weather warning service. Low, mid, and high cloud fractions are numerical
weather model fields, not a satellite cloud mask. Wispy high cloud is used
only when the high-layer fraction is present and dominates the lower layers.
The original offline Earth maps retain their attribution in earth_credits.txt.

Cloud density library and editable models authored for Meta Theatre in Blender;
shared-atlas preview materials authored in the separate Unreal asset sandbox.

Continuous cloud morphology derives from the attributed Solar System Scope /
INOVE Earth cloud map (CC BY 4.0), with ranked density, warped fronts, spherical
polar convergence and procedural erosion authored in Blender. See earth_credits.txt
for the source link and license. Live data controls coverage and cloud type;
this derived morphology is not a live satellite product.
